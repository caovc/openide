## Result

- Shared Variables and Plots tool windows registered through the existing
  contribution system. Both use one session selector, native accessible
  controls, CSS Modules and existing tokens. Variables show name, type, summary
  and lazy children; plots show image output history with previous/next controls.
- Every native kernel generation owns separate SessionData. Both the project
  incarnation's runtime namespace and authorized notebook/Console document path
  must match. Same-file sessions in different project instances cannot borrow
  data. Restart creates empty state; old stop tokens, generations, revisions,
  request ids and out-of-order Ark versions cannot repopulate it.
- The existing shared KernelManager execution path initializes the selected
  adapter. Python keeps ipykernel and receives an isolated, history-free
  variables comm helper with a post-execution refresh callback. Ark uses its
  public `positron.variables` refresh/update/inspect protocol. Ark RPC parent
  header correlation and Python data.id correlation are handled independently.
- Jupyter image display/update output and public Ark plot pre-renders feed
  history. History is bounded to 50 images / 16 MiB per generation. Evicted plot
  updates do not resurrect entries. HTML is not rendered in the workbench;
  SVG stays inside an image element.
- Variable/plot comms owned by U6 are consumed before the general subscription
  bus, preserving existing LSP, DAP and custom comm subscriber behavior. Other
  execution, stdin and DAP routing remains in the existing implementation.
- Lazy requests are bounded and cleaned on cancellation/timeout. Both Rust and
  frontend guards reject results after mutation, reset, close, project
  replacement or generation changes. Closed document sources are removed on
  polling. A stopped kernel retains no visible variables or plots.
- Language adapter contract and explicit unavailable SAS stub are documented in
  `src/features/ds-session/ADAPTER.md`. No SAS runtime implementation or new
  dependency was added.

The source is connected to actual execution plumbing; the environment prevented
executing that connection end to end. Runtime compatibility remains unverified.
