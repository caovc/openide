# U9 Phase 0 — source and license audit

Status: **research/docs only; no component adoption or installation approved**.
Audited 2026-11-06 (Asia/Shanghai, UTC+8). Package versions below are registry responses observed this turn, not assumptions about a search index or a promise that `latest` is stable. This is an engineering gate, not a legal opinion.

## Decision

**Recommend the existing React 19 + `@tanstack/react-virtual@3.14.21` stack, an independently written typed/paged table provider, and existing OpenIDE tokens.** First reuse the database grid's interaction patterns; do not import the database feature into the new feature. A future approved shared primitive extraction must preserve database behavior. Add horizontal virtualization and typed-cell presentation behind the renderer boundary when implementation is authorized.

There is **no verified, standalone permissive Databricks canvas dataframe viewer in the candidates examined**. This is a bounded finding, not a claim that none exists. `dbx` is the Databricks CLI extension, not a React viewer, and its actual license is restricted. AppKit has a genuinely Apache-licensed React table, but it is DOM/table-and-query scaffolding rather than the desired local high-performance engine. Du Bois is a design system, not a drop-in dataframe explorer.

## Candidate decisions

GO-license means the inspected direct artifact has a usable permissive license; it does **not** approve installation, all transitives, runtime fitness, trademarks, or copying unrelated UI.

## Direct evidence and reproducibility

- `.audit/u9-verification.tsv` records each public read, response/failure, and local evidence path. Requests are read-only; npm tarballs were inspected in memory and only license/notice/readme/manifest files saved. Nothing was installed or executed from those packages.
- `.audit/u9-sources/*.json` preserves registry version, repository, license, peers/dependencies, tarball URL and registry integrity when supplied. `*--package__LICENSE*` / `NOTICE*` preserve exact distributed notices. `SHA256SUMS.tsv` fingerprints the saved evidence.
- Public AppKit table source inspected: [data-table.tsx](https://github.com/databricks/appkit/blob/main/packages/appkit-ui/src/react/table/data-table.tsx). Saved snapshot is dated, hashed research evidence from moving `main`, **not** claimed to be the 0.90.0 source revision. Exact 0.90.0 license decision is based on its published artifact, not `main`.
- Public Ark pinned schema: [data_explorer_comm.rs](https://github.com/posit-dev/ark/blob/670a4946d8c3887e04591e4103b21fdba503afa3/crates/amalthea/src/comm/data_explorer_comm.rs). `get_state`, `get_schema`, `get_data_values`, `set_row_filters`, `set_sort_columns`, async `get_column_profiles`, feature statuses and profile callbacks establish a protocol candidate, not working OpenIDE support.
- dbx [PyPI metadata](https://pypi.org/pypi/dbx/json) identifies version; tagged license text overrides any guessed SPDX label. No dbx implementation code copied.
- Search findings were used for discovery only. Authoritative npm metadata and shipped license files override stale indexed versions (e.g. Du Bois search result 2.0.9 versus fetched 2.0.16).

## Existing OpenIDE reuse (read-only inspection)

- Root `LICENSE` is Apache-2.0; existing `NOTICE` records current upstream attributions. Do not infer that every proprietary product from those vendors is reusable.
- `src/features/database/Grid.tsx`: row virtualization through TanStack, 24px rows, overscan 12, column resizing, range keyboard selection, copy/TSV/CSV, null display, sort/filter callbacks, cell preview. It is a DOM grid with **no horizontal virtualizer** today.
- `database/DataView.tsx`: loaded-row local filter/sort/search and Record/Value/Aggregates views. Useful behavior specifications, **not whole-session queries or whole-frame summaries**.
- `database/model.ts:15` models `Cell = string | null`; it is unsuitable as the canonical R/Python/SAS value model. Never flatten typed data to strings upstream merely to fit it.
- `database/{ChartView,ExportDialog,ColumnsPopup,cellPreview,resultView}` are reuse candidates after typed/bounded adapters and ownership review. SQL connection/store/edit state is not a session backend.
- `src/styles/tokens.css`, database CSS and session CSS already provide `--bg-editor`, `--bg-editor-gutter`, `--bg-editor-selection`, `--bg-input`, `--border`, `--font-ui`, `--font-mono`. Use them to match OpenIDE's JetBrains-oriented density rather than importing vendor themes/assets.

## Redistribution / adoption gate

1. Before adoption, pin exact direct and transitive versions, inspect their licenses/NOTICES and shipped assets/fonts, and generate a desktop-distribution third-party notice inventory. This Phase 0 is **not** an exhaustive dependency/security audit.
2. MIT: retain copyright and permission notice. Apache-2.0: include license and applicable NOTICE/attribution; mark modified upstream files. Respect trademark exclusions; do not reuse vendor branding. ISC candidate remains blocked until actual terms and provenance are verified.
3. No copied JetBrains DataSpell/IDEA proprietary implementation, Positron UI, logos or screenshots/assets as product resources. Public protocol documentation and clean-room interaction requirements are separate from UI source reuse.
4. Any prospective package install remains **PROPOSED, NOT APPROVED**. Phase U9.1 proposed new npm packages: **none**. Alternatives listed above are research candidates, not authorization to install. Glide's lodash/marked/carousel peers and any other transitive additions require a separate exact-version proposal if selected.

## Blockers / outcome

- User's “dbx” component is not identified by a precise package; do not assume a proprietary Databricks notebook grid is open source. Proceed with provider design independently of that ambiguity.
- Du Bois provenance/license-text gap; Glide React 19 artifact mismatch; AppKit is permissible but architecturally excessive.
- R explorer comm startup/capability and Python dataframe-safe bounded access are unimplemented/unverified; no U9 runtime or desktop performance acceptance is claimed.
- Recommended smallest unit after coordinator approval: U9.1 **transport-neutral schema + provider contract + conformance fixtures**, no production viewer and no new npm dependencies. See architecture sketch for the next gated vertical slice.
